## Refresh policy

Before an external action, recheck current provider permissions, eligibility, limits, pricing, and policy. Check the installed SDK and actual repository before applying API guidance. When sources disagree, preserve both and record the unresolved scope instead of merging them into a confident claim. Refresh the affected chapter, playbook, source record, and manifest together. Stable strategy principles do not require daily rewriting; volatile execution details do.

No live customer data, deployed ClimbOS integration, paid advertising experiment, or measured business uplift was created or validated during this authoring project.

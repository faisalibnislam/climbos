Two proposed posts per platform, with synthetic repair-kit facts, no verified destination, no trends, images, audience or publishing permission. Every case returned schema-valid drafts; none passed the production critic.

Failures included weak/repeated angles, poor fact citation, missing practical guide access, thin Facebook copy, video drafts labelled as text/threads, and two deterministic false positives. The writer's shared context omitted the separate numbered fact list; some production briefs already include facts, so this standalone evaluation amplified that omission and is not proof that every production writer lacked facts. Palette hexadecimal values were wrongly treated as business statistics, and “end on the hinge” was wrongly treated as an expiring offer. Subsequent fixes preserve real claim checks while addressing these cases. Early social fingerprints read files during a long-running process; saved inputs and receipts are retained, but the code fingerprint alone does not reproduce every loaded module. The runner now freezes the social source hash at startup.

## Repairs after the live runs

Current engine `v3.80-numbered-facts-and-focused-cycles` adds the numbered, source-labelled fact list to shared writer/reviewer context; requires every hard gate exactly once; constrains funnel shares to 0–1; rejects a wrong requested social channel and inappropriate video formats; and fixes the palette/filming false positives. Regression tests cover these repairs. These final changes have **not** been validated in another paid model run. They do not convert any recorded failure into a pass.
